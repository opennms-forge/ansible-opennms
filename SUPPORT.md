# Support

## Questions about this collection

Open a [GitHub issue](https://github.com/opennms-forge/ansible-opennms/issues/new/choose) and pick the enhancement form, or a blank issue for a question. Say which inventory shape you are deploying, which role failed, and paste the task output. Issues are the only tracked channel; Discussions is not enabled here.

## Questions about OpenNMS itself

This collection only deploys OpenNMS. For how OpenNMS behaves once it runs, its configuration, or troubleshooting the product, ask the OpenNMS community:

- [OpenNMS Discourse](https://opennms.discourse.group), tag your post `sig-ansible` if it touches this collection
- [OpenNMS Mattermost](https://chat.opennms.com/opennms/channels/opennms-discussion)

## Security

Do not open a public issue. See [SECURITY.md](SECURITY.md) for private vulnerability reporting.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md). Work starts from an issue, and every commit carries a DCO sign-off.
